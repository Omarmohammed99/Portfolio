Flagship / Graduation Project

Sentinel AI — Automated Traffic Accident Detection

An end-to-end AI-powered traffic safety pipeline that processes real-time video streams, detects vehicular accidents, classifies ego-vehicle involvement, and generates automated incident reports using Vision-Language Models.

System Architecture

Video Input

Real-time video stream

Frame Sampling

16 uniform frames via OpenCV

Tier 1 Inference

MobileNet + LSTM detection

Tier 2 Inference

Ego-vehicle classification

Gemini Flash API

VLM keyframe reasoning & summary

JSON API Response

Structured incident report payload

Key Features

  • Multi-Tier AI Pipeline

    Tier 1 — sequential MobileNet + LSTM for real-time crash detection. Tier 2 — ego-vehicle involvement classification.

  • VLM Reasoning Layer

    Gemini Flash API analyzes keyframes to detect context and generate structured incident summary reports.

  • Low-Latency Architecture

    Optimized 16-frame uniform sampling via OpenCV for ultra-fast model inference.

  • Automated Model Fetching

    Seamless Hugging Face Hub integration downloads weights on initial launch.

  • Production API

    Built with Flask and Werkzeug, containerized with Docker for reproducible deployment.
